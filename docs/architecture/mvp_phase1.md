# MVP Phase 1

Phase 1 establishes the executable scaffold for the Repo + Dependency Context MCP MVP.

## Goals

- Start a FastAPI application
- Centralize environment-driven settings
- Centralize logging configuration
- Prepare SQLAlchemy and Alembic integration points
- Prepare Celery integration points
- Keep interfaces small and replaceable

## Out of scope

- No business models yet
- No ingest logic yet
- No retrieval logic yet
- No MCP tools yet
